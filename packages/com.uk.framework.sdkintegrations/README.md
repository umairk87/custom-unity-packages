# UK Framework SDK Integrations

A simple reusable Unity service layer for:

- Platform SDKs
- Ads
- Analytics
- Manual Unity builds
- Unity CLI builds
- Multiple build profiles
- Enabling/disabling complete systems
- Enabling/disabling individual providers

Designed for Unity 6 and compatible with a project-level ServiceLocator.

## 1. Install

Copy:

    Runtime/
    Editor/

into your project, or package this folder as:

    Packages/com.uk.framework.sdkintegrations/

The included asmdefs can remain in the package.

## 2. Create the config

In Unity:

Tools -> UK Framework -> SDK Integrations Build Profiles

Click:

Create Config

This creates:

    Assets/Resources/SDKIntegrationsConfig.asset

## 4. Disable everything

Set:

    PlatformEnabled = false
    AdsEnabled = false
    AnalyticsEnabled = false

The game-facing APIs remain safe to call and simply do nothing.

## 5. Disable one provider

Example:

    AdsEnabled = true

    AdMob       Enabled = true
    Unity Ads   Enabled = false

The ads service only considers enabled providers.

## 6. Provider priority

Lower priority number means first.

Example:

    AdMob      0
    Unity Ads 10

When ShowRewarded() is called:

    AdMob request
        -> if provider cannot accept request
    Unity Ads request

Only one provider is requested.

Portal SDKs such as CrazyGames/Poki are normally used as a single-provider profile.

## 7. SDK defines

The framework expects SDK installation defines:

    UK_SDK_CRAZYGAMES
    UK_SDK_POKI
    UK_SDK_ADMOB
    UK_SDK_UNITYADS
    UK_SDK_FIREBASE

These should be generated by your existing AutoDefine/package detection system.

Do not use UK_SERVICE_* as a replacement for SDK detection.

The build profile owns activation.

## 8. CrazyGames

Install the official CrazyGames Unity SDK.

Enable:

    UK_SDK_CRAZYGAMES

The CrazyGames adapters wrap:

    CrazySDK.IsAvailable
    CrazySDK.Init()
    CrazySDK.Game.GameplayStart()
    CrazySDK.Game.GameplayStop()
    CrazySDK.Ad.RequestAd(...)

CrazyGames currently documents Unity gameplay lifecycle methods and video ad requests this way.

## 9. Poki

Install the official Poki Unity SDK for your Unity version.

Enable:

    UK_SDK_POKI

The Poki adapters wrap:

    PokiUnitySDK.Instance.init()
    PokiUnitySDK.Instance.gameLoadingFinished()
    PokiUnitySDK.Instance.gameplayStart()
    PokiUnitySDK.Instance.gameplayStop()
    PokiUnitySDK.Instance.commercialBreak()
    PokiUnitySDK.Instance.rewardedBreak()
    PokiUnitySDK.Instance.measure(...)

## 10. Game integration

Create a SDKIntegrationsBootstrap GameObject in your bootstrap scene.

Assign:

    SDKIntegrationsConfig

Set the default profile:

    mobile

Register the services with your existing ServiceLocator:

    ServiceLocator.Register<PlatformService>(SDKIntegrationsRuntime.Platform);
    ServiceLocator.Register<AdsService>(SDKIntegrationsRuntime.Ads);
    ServiceLocator.Register<AnalyticsService>(SDKIntegrationsRuntime.Analytics);

If you prefer interfaces, add small wrapper registrations for your project's interfaces.

## 11. Gameplay

At actual gameplay start:

    SDKIntegrationsRuntime.Platform?.GameplayStart();

At pause/menu/level end:

    SDKIntegrationsRuntime.Platform?.GameplayStop();

When loading is complete:

    SDKIntegrationsRuntime.Platform?.GameLoadingFinished();

For your Cannon game, the best place is the existing GameState service/controller.

## 12. Ads

Interstitial:

    SDKIntegrationsRuntime.Ads?.ShowInterstitial(result =>
    {
        // Completed / Failed / etc.
    });

Rewarded:

    SDKIntegrationsRuntime.Ads?.ShowRewarded(result =>
    {
        if (result == AdsShowResult.Completed)
        {
            GiveReward();
        }
    });

Banner:

    SDKIntegrationsRuntime.Ads?.ShowBanner();

Hide:

    SDKIntegrationsRuntime.Ads?.HideBanner();

## 13. Analytics

    SDKIntegrationsRuntime.Analytics?.TrackEvent(
        "level",
        levelIndex.ToString(),
        "start");

For example:

    level / 1 / start
    level / 1 / complete
    level / 1 / fail

## 14. Manual build

Open:

    Tools -> UK Framework -> SDK Integrations Build Profiles

Select:

    CrazyGames

Then:

    Use Profile
    Build

The build processor reads the selected profile automatically.

## 15. CLI

Your existing UnityCLI should call:

    SDKIntegrationsCLI.ApplyCommandLineProfile();

before BuildPipeline.BuildPlayer.

Then:

    ./unity build webgl --profile crazygames

or:

    ./unity build webgl --profile poki

or:

    ./unity build android --profile mobile

The CLI --profile overrides the editor selection for that build.

Do not modify SDKIntegrationsConfig.asset during CI.

## 16. Important SDK note

This package intentionally keeps vendor-specific code inside provider adapters.

If the installed version of a vendor SDK changes a method name, only the corresponding provider file should change.

Do not put vendor SDK calls into game code.

## 17. Portal ads

CrazyGames and Poki control ad availability and timing through their SDKs. Therefore the generic layer does not invent an IsReady check for those providers.

A provider's Show* method returns true when the request was accepted.

The callback reports the eventual result.

Do not automatically start another provider after a portal ad request has already started.

## 18. Recommended final architecture

    Game
      |
      +-- PlatformService
      |      |
      |      +-- CrazyGames
      |      +-- Poki
      |      +-- Null
      |
      +-- AdsService
      |      |
      |      +-- CrazyGames
      |      +-- Poki
      |      +-- AdMob
      |      +-- Unity Ads
      |      +-- Null
      |
      +-- AnalyticsService
             |
             +-- CrazyGames
             +-- Poki
             +-- Firebase
             +-- Null

Build profile decides which providers are active.

SDK defines decide which SDKs are installed.

Game code never references a vendor SDK directly.


## 21. Optional gameplay bridge

`Runtime/SDKIntegrationsGameplayBridge.cs` is a small optional helper. It does not replace your existing GameState system.

Call:

    LoadingFinished()
    GameplayStarted()
    GameplayStopped()

from your existing game-state transitions.

For the Cannon project, wire these from the existing `IGameStateService` / `GameStateChangedData` flow.

## 22. What is intentionally not included

The package does not guess vendor APIs for every mobile ads SDK version.

AdMob and Unity Ads files are adapter boundaries. Once your exact installed SDK versions are known, put the vendor calls only in those files.

This prevents vendor API changes from leaking into the framework.

## 23. SDK/profile separation

`UK_SDK_*` means the vendor SDK is installed.

`UK_SERVICE_*` means the provider is active for the current build.

The current runtime factory uses `UK_SDK_*`; profile enable/disable is enforced by `SDKIntegrationsBootstrap`.

This means you can install all SDKs while building a profile that uses only one.

## 24. Portal lifecycle

CrazyGames:
- `GameplayStart`
- `GameplayStop`

Poki:
- `GameLoadingFinished`
- `GameplayStart`
- `GameplayStop`

Poki commercial/rewarded breaks are exposed through the Poki ads provider.

Do not call vendor SDK methods directly from gameplay code.
