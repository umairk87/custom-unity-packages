# UK Framework - Game

A reusable Unity game framework providing common runtime systems and foundations shared across multiple games.

## Package

**Package ID**

`com.uk.framework.game`

**Display Name**

`UK Framework - Game`

## Features

- Game Bootstrap foundation
- Service Locator
- Service initialization
- Audio system
- Object pooling
- Event Bus
- Progress / save system
- Game State Machine
- Generic game states
- UI service foundation
- Level service
- Reusable game configuration
- Runtime-created services and objects

## Requirements

- Unity 6.0 or later
