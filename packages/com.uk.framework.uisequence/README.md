# UK Framework - UI Sequence

A reusable Unity UI animation sequencing system for creating, editing, and controlling UI animations through configurable sequences.

The package provides a visual EditorWindow for building animation sequences and a runtime system for executing them.

## Features

- Sequence-based UI animation
- Multiple actions per sequence
- Position animation
- Scale animation
- Rotation animation
- Anchored position animation
- Delay actions
- Function/method callbacks
- Configurable animation duration
- Configurable easing
- Looping animations
- Runtime loop control
- Stop running sequences
- DOTween-based tween execution
- Custom Unity EditorWindow
- Scene/GameObject references
- Editor and Runtime assembly separation

## Requirements

- Unity 6.0 or later
- DOTween
