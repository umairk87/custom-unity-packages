# Custom Unity Packages

A collection of reusable Unity packages developed by Umair Khalid.

## Packages

### UI Sequence

`com.uk.framework.uisequence`

Reusable UI animation sequencing system for Unity.

### Audio System

`com.uk.framework.audio`

Reusable audio management system for Unity.

### Level System

`com.uk.framework.levelsystem`

Reusable level creation and management system for Unity.

## Requirements

Unity 6+

## Installation

Each package can be installed independently through Unity Package Manager.
